# Sohan Mandal | Software Engineering Portfolio

Personal portfolio website built with Next.js, TypeScript, and Tailwind CSS, showcasing projects, skills, achievements, and internship-focused experience.

## Overview
This is a minimalist and highly optimized portfolio engineered to highlight technical capabilities and software engineering projects. It is fully responsive, supports dark mode, and strictly adheres to accessibility and SEO best practices (Lighthouse score 98+).

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Icons:** React Icons & Lucide React

## Local Development
To run this project locally, clone the repository and install dependencies:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Architecture & Customization
All portfolio content (Education, Projects, Skills, Contact info) is centrally managed inside a strictly typed data schema located at `src/data/portfolio.ts`. 
No UI component editing is required to add new projects or update existing information.
